# Дорожная карта проекта

> Tasker — простой таск-трекер с рабочими пространствами, канбан-доской и списком, задачами в нескольких проектах, документацией и интеграцией с GitHub.

## Этапы

- [x] **Каркас проекта** — Next.js + TypeScript, Tailwind + shadcn/ui, Prisma + PostgreSQL, docker-compose (Postgres, MinIO), логгер, единый формат ошибок, линтеры
- [ ] **Аутентификация и глобальные роли** — Better Auth, регистрация и вход, роль администратора ресурса
- [ ] **Рабочие пространства и доступы** — создание пространства, приглашения, участники, роли владельца и участника, общий слой проверки доступа
- [ ] **Проекты и статусы** — проекты в пространстве, настраиваемые колонки-статусы
- [ ] **Задачи** — срок, приоритет, ответственный, описание; размещение одной задачи в нескольких проектах со своим статусом в каждом
- [ ] **Канбан-доска** — перетаскивание карточек между колонками и внутри колонки
- [ ] **Представление списком** — таблица задач с фильтрами, сортировкой и пагинацией
- [ ] **Комментарии к задачам** — обсуждение задачи участниками пространства
- [ ] **Вложения** — загрузка файлов в S3/MinIO по временным ссылкам, ограничения по размеру и типу
- [ ] **Администрирование ресурса** — панель администратора для управления пользователями и пространствами
- [ ] **Проектная документация** — иерархия страниц, редактор Tiptap, привязка документов к задачам
- [ ] **Интеграция с GitHub** — GitHub App, вебхуки, автоматическая привязка задач к PR, статус PR в задаче
- [ ] **Готовность к продакшену** — Docker-образ, CI, e2e-тесты, аудит безопасности
