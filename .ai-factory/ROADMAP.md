# Дорожная карта проекта

> Tasker — простой таск-трекер с рабочими пространствами, канбан-доской и списком, задачами в нескольких проектах, документами пространства и интеграцией с GitHub.

## Этапы

- [x] **Каркас проекта** — Next.js + TypeScript, Tailwind + shadcn/ui, Prisma + PostgreSQL, docker-compose (Postgres, MinIO), логгер, единый формат ошибок, линтеры
- [x] **Аутентификация и глобальные роли** — Better Auth, регистрация и вход, роль администратора ресурса
- [x] **Рабочие пространства и доступы** — создание пространства, приглашения, участники, роли владельца и участника, общий слой проверки доступа
- [x] **Проекты и статусы** — проекты в пространстве, настраиваемые колонки-статусы
- [x] **Задачи** — срок, приоритет, ответственный, описание; размещение одной задачи в нескольких проектах со своим статусом в каждом
- [x] **Канбан-доска** — перетаскивание карточек между колонками и внутри колонки
- [x] **Представление списком** — таблица задач с фильтрами, сортировкой и пагинацией
- [x] **Комментарии к задачам** — обсуждение задачи участниками пространства
- [x] **Вложения** — загрузка файлов в S3/MinIO по временным ссылкам, ограничения по размеру и типу
- [x] **Профили и уведомления** — фото, должность и описание; публичный профиль и карточка участника; @упоминания в комментариях; уведомления в приложении и письмом с настройкой каналов
- [x] **Интерфейс и удобство** — редизайн каркаса, тёмная тема, панель задачи поверх доски и списков, перетаскивание статусов в настройках проекта
- [ ] **Администрирование ресурса** — панель администратора для управления пользователями и пространствами
  - [x] Пользователи — список, блокировка, роли, завершение сессий, удаление (план `admin-users`)
  - [ ] Пространства — список, удаление, смена владельца, доступ администратора
- [x] **Документы пространства** — своё хранилище с квотой, папки и теги, Markdown-заметки с редактором, просмотр файлов (картинки, PDF, текст, CSV, JSON, медиа), привязка документов к задачам (план `workspace-documents`)
- [x] **Интеграция с GitHub** — GitHub App, вебхуки, автоматическая привязка задач к PR, статус PR в задаче; ветки и коммиты, автосмена статуса, уведомления, вход через GitHub (план `github-integration`)
- [ ] **Готовность к продакшену** — Docker-образ, CI, e2e-тесты, аудит безопасности
  - [x] Docker-образ и CI — `Dockerfile` (`runner` + `migrate`), `compose.app.yml`, GitHub Actions (план `feature-docker-ci`, PR #1)
  - [ ] e2e-тесты — Playwright: регистрация → пространство → проект → задача → доска → комментарий с @упоминанием → приглашение; запуск в CI на чистом Postgres
  - [ ] аудит безопасности — фильтр по `workspaceId` во всех read-функциях и MCP-инструментах, presigned-ссылки, MIME при загрузке, рендер Markdown, подпись вебхуков
- [x] **Безопасность аутентификации** — недостающие сценарии Better Auth перед продакшеном (план `auth-security`)
  - [x] Сброс пароля по email (`sendResetPassword`)
  - [x] Подтверждение email при регистрации (`emailVerification`)
  - [x] Rate limit в хранилище `database` вместо `memory`
  - [x] Двухфакторная аутентификация (плагин `twoFactor`) и список активных сессий в профиле
- [ ] **Расширение задач** — функции, ожидаемые от таск-трекера
  - [ ] История изменений задачи — статус, ответственный, срок и др., включая правки агентов через MCP
  - [ ] Метки (labels) у задач
  - [ ] Глобальный поиск и палитра Cmd+K — задачи по ключу и названию, документы, участники
  - [ ] Архив вместо удаления — задачи, проекты, пространства (`archivedAt`)
  - [ ] Наблюдатели задачи
  - [ ] Напоминания о сроке и просрочке — планировщик (cron-контейнер или systemd-таймер)
  - [ ] Связи между задачами — «блокирует», «дублирует»
  - [ ] Массовые действия в списке — статус, ответственный, проект
- [ ] **Удобство работы** — скорость и обзор
  - [ ] Обновления в реальном времени (SSE) для доски и комментариев
  - [ ] Сохранённые фильтры списка и «Мои задачи» по всем пространствам
  - [ ] Горячие клавиши на доске и в панели задачи
  - [ ] Экспорт задач в CSV, импорт из Trello / Jira
  - [ ] Дашборд пространства — открытые и просроченные задачи, нагрузка по участникам
- [ ] **Эксплуатация** — наблюдаемость и надёжность
  - [ ] Error tracking и метрики (Sentry / OpenTelemetry) поверх pino
  - [ ] Регулярная проверка восстановления из бэкапа
  - [ ] Очистка «сиротских» объектов в S3 после удалений и неудачных загрузок
