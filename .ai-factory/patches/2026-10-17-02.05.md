# Настройки проекта: секции без карточек, компактная раскладка

**Дата:** 2026-10-17 02:05
**Файлы:** src/components/layout/settings-section.tsx (новый), src/app/(app)/w/[workspaceSlug]/projects/[projectId]/settings/page.tsx, src/components/projects/{status-row,status-list,add-status-form,project-settings-form}.tsx, src/components/entity-icon/entity-icon-picker.tsx
**Severity:** low

## Problem

Страница настроек проекта выглядела растянутой: четыре карточки с фоном и обводкой во всю ширину (max-w-4xl), описание над содержимым, у каждой строки статуса — своя рамка с фоном, у формы добавления — пунктирная рамка. Настроек мало, а места занято много.

## Root Cause

Каждая секция оформлялась как `Card` (фон + ring), и вложенные элементы повторяли тот же приём (рамка на строку). Вертикальная раскладка «заголовок → описание → поля» тратила высоту, а поля тянулись на всю ширину карточки.

## Solution

- `SettingsSection` / `SettingsSections`: без фона и обводки; на lg+ две колонки — слева заголовок и пояснение (15rem), справа поля (до 48rem); секции разделены `divide-y` с еле заметной линией. «Опасная зона» — красный заголовок вместо красной рамки.
- Статусы — список с разделителями (`divide-y` + `border-y`) вместо рамок на строку; при перетаскивании строка по-прежнему поднимается (фон, тень, кольцо). Форма добавления — без пунктирной рамки и фона.
- Форма «Основное» ограничена `max-w-xl`, иконки в настройках — в один ряд (`gridClassName="sm:grid-cols-10"`, в узкой панели остаётся 5×2).
- Ширина колонки полей (48rem) совпадает с контейнерным брейкпоинтом `@3xl` строк статусов — на десктопе строка статуса остаётся однострочной.

## Prevention

- Для страниц настроек использовать `SettingsSection`, а не `Card`: карточки — для сущностей в списках, не для групп полей.
- Не вкладывать рамку в рамку: внутри секции — разделители.
- Меняя ширину колонки, проверять контейнерные брейкпоинты (`@3xl` = 48rem) вложенных компонентов.

## Дополнение: кнопки и строка нового статуса

- «Сохранить» в «Основном» — `size="sm"` и неактивна, пока нет правок (как «Сохранить» в строках статусов). Признак правки — `editedFor === state`: `onChange` формы запоминает текущий ответ сервера, новый ответ сбрасывает признак без эффектов; при ошибке кнопка остаётся активной.
- Новый статус свёрнут в ghost-кнопку «+ Добавить статус»; раскрытая форма повторяет колонки `StatusRow` (кнопка `@3xl:w-24` у обеих, место счётчика `w-18`, иконка справа — «Отмена»), «Добавить» — `secondary`. Esc закрывает форму, кроме Esc из выпадающего списка (портал вне DOM формы — проверка `currentTarget.contains(target)`).
- «Опасная зона» → «Удаление проекта» обычным заголовком; кнопка — `outline` `sm` с красным текстом вместо залитой `destructive`. Проп `destructive` у `SettingsSection` удалён.

**Prevention:** в одной форме все действия одного размера и одной логики активности; строка добавления в таблице-списке повторяет колонки строк (фиксированная ширина кнопок), иначе колонки «съезжают»; залитые кнопки — только для главного действия диалога, не для действий в потоке страницы.
