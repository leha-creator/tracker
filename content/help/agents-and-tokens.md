Claude Code подключается к Tasker по токену доступа. Токен бывает двух видов: токен агента пространства, который действует от имени отдельного участника-агента, и личный токен, который действует от вашего имени. Как подключить Claude Code с готовым токеном, описано в статье [Claude Code и MCP](/help/claude-code-mcp).

## Агент или личный токен

| | Агент пространства | Личный токен |
|---|---|---|
| От чьего имени работает | От имени агента, например «Claude — backend» | От вашего имени |
| Кто выпускает токен | Владелец пространства | Любой участник, для себя |
| Автор задач, комментариев, документов | Агент | Вы, с пометкой «через Claude Code» |
| Права | Права агента | Ваши права |
| Кому приходят уведомления | Ответственному за агента | Вам |

Агент подходит, когда Claude Code работает сам по себе, например по агенту на репозиторий: в истории задач видно, что сделал именно агент. Личный токен подходит, когда вы работаете вместе с Claude Code на своём компьютере.

## Агенты пространства

Агент — отдельный участник пространства для Claude Code. У него своё имя, ответственный и права. В списке участников он отмечен «Агент». Агента можно назначить ответственным за задачу и упомянуть в комментарии.

Войти в интерфейс агент не может: у него нет пароля и почты, он работает только по токену.

Создавать агентов и управлять ими может только владелец пространства. Путь к разделу: «Настройки» пространства → «Агенты» → «Настроить агентов».

![Список агентов пространства «Студия Север»](/help-media/agents-and-tokens/agents.png "Раздел «Агенты»: агент «Claude — backend» и его ответственный")

### Создать агента

1. Откройте раздел «Агенты» и нажмите «Создать агента».
2. Заполните «Название», например «Claude — backend».
3. В поле «Описание» укажите репозиторий или зону ответственности агента.
4. Выберите «Ответственный» — участника-человека, который будет получать уведомления агента.
5. В блоке «Права в пространстве» отметьте нужные права: «Управление проектами» и «Управление документами».
6. Нажмите «Создать агента».

![Диалог «Новый агент»](/help-media/agents-and-tokens/new-agent.png "Новый агент: название, описание, ответственный и права")

В пространстве может быть не больше 20 включённых агентов.

### Ответственный

Агент сам не читает уведомления. Всё, что адресовано агенту (упоминания, назначение ответственным, комментарии), получает его ответственный. Если ответственный вышел из пространства, уведомления получают владельцы пространства. О своих собственных действиях ответственный уведомлений не получает.

### Права агента

Без отмеченных прав агент работает как обычный участник: читает задачи и документы, создаёт и меняет задачи и комментарии. Права добавляют:

- «Управление проектами» — как у участника с этим правом.
- «Управление документами» — без него агент только читает документы.

Чтобы поменять права, нажмите «Изменить» в списке агентов.

### Токены агента

1. Нажмите на название агента в списке. Откроется страница агента.
2. В блоке «Токены агента» нажмите «Создать токен».
3. Укажите «Название», «Срок действия» и «Области» (о них ниже) и нажмите «Создать».
4. Скопируйте токен и команды подключения. Токен показывается один раз.

Выпускайте отдельный токен на каждое место запуска: ноутбук, сервер CI. Тогда лишний токен можно отозвать, не трогая остальные.

![Страница агента «Claude — backend»](/help-media/agents-and-tokens/agent.png "Страница агента: токены и журнал действий")

### Журнал действий агента

На странице агента, в блоке «Журнал действий», видно, что агент изменил через MCP: задачи, статусы, комментарии, файлы и документы. У каждой записи есть время, токен и инструмент. Чтение в журнал не попадает. Записи хранятся 90 дней.

### Отключить и включить агента

Кнопка «Отключить» в списке агентов:

- отзывает все токены агента;
- убирает агента из участников и снимает с него задачи.

Задачи, комментарии и документы, которые агент создал, остаются с его именем.

Кнопка «Включить» возвращает агента в участники, но без дополнительных прав. Права нужно выдать заново через «Изменить», а токены выпустить заново.

## Личные токены

Личный токен даёт Claude Code доступ к одному пространству с вашими правами. Выпустить его может любой участник пространства.

1. Откройте профиль, вкладку «Токены доступа».
2. Нажмите «Создать токен».
3. Заполните «Название», например «Claude Code — ноутбук».
4. Выберите «Пространство». Токен будет работать только в нём.
5. Выберите «Срок действия»: «30 дней», «90 дней», «1 год» или «Бессрочно».
6. Отметьте «Области» и нажмите «Создать».
7. Скопируйте токен и команды подключения. Токен показывается один раз: после закрытия окна его не посмотреть.

![Вкладка «Токены доступа» в профиле](/help-media/agents-and-tokens/personal-tokens.png "Личный токен «Claude Code — ноутбук» в пространстве «Студия Север»")

В списке токенов видно пространство, области, когда токен использовали в последний раз, когда он истекает и его статус: «Действует», «Истёк» или «Отозван».

### Журнал токена

Ссылка «Журнал» под названием токена открывает изменения, которые агент сделал этим токеном. Журнал личного токена видите только вы. Записи хранятся 90 дней.

![Журнал личного токена](/help-media/agents-and-tokens/token-activity.png "Журнал токена «Claude Code — ноутбук»")

## Области токена

Области определяют, что агент может менять. Их выбирают при выпуске токена, потом изменить нельзя. Если нужны другие области, выпустите новый токен.

| Область | Что разрешает |
|---------|---------------|
| «Чтение» | Задачи, проекты, документы и участники — только чтение. Есть у любого токена |
| «Задачи» | Создание и изменение задач, статусов, комментариев и вложений |
| «Документы» | Создание и изменение документов: заметки, файлы, папки, теги, связи с задачами |

Область не расширяет права. Чтобы агент менял документы, нужны и область «Документы», и право «Управление документами» у владельца токена.

## Отозвать токен

1. Найдите токен в списке: в профиле на вкладке «Токены доступа» или на странице агента.
2. Нажмите «Отозвать» и подтвердите.

Доступ пропадает сразу. Отменить отзыв нельзя, понадобится новый токен.

Токен также перестаёт работать сам, если:

- истёк его срок;
- вы вышли из пространства или вас из него удалили;
- агента отключили;
- пространство перенесли в архив.

Храните токен как пароль: не коммитьте его в репозиторий и не вставляйте в задачи и PR. Админских прав у токена нет никогда.

## Пометка «через Claude Code»

Задачи, комментарии и документы, созданные по личному токену, Tasker помечает «через Claude Code». Если навести на пометку, появится название токена. Пометка стоит в шапке комментария, в строке «создана» у задачи, в сведениях о документе и в истории задачи.

![Комментарий с пометкой «через Claude Code»](/help-media/agents-and-tokens/via-agent.png "Комментарий Анны Смирновой, написанный через Claude Code")

У того, что создал агент пространства, такой пометки нет: автором и так указан агент.

## Если что-то не получается

**Нет раздела «Агенты» в настройках или страница не открывается.** Агентами управляет только владелец пространства. Попросите владельца создать агента или выпустите личный токен.

**Кнопка «Создать агента» неактивна.** В пространстве уже 20 включённых агентов. Отключите ненужного.

**Кнопка «Создать токен» на странице агента неактивна.** Агент отключён. Нажмите «Включить» в списке агентов.

**Кнопка «Создать токен» в профиле неактивна.** Вы не состоите ни в одном пространстве. Токен выпускается для конкретного пространства.

**«Не больше 20 действующих токенов. Отзовите ненужные».** У пользователя или агента может быть не больше 20 действующих токенов. Отзовите те, что больше не нужны.

**Claude Code перестал подключаться.** Токен истёк, отозван, вас удалили из пространства или агента отключили. Проверьте статус токена в списке и при необходимости выпустите новый.

**Агент не может менять документы.** У токена нет области «Документы» или у агента нет права «Управление документами». Право выдаёт владелец через «Изменить», область задаётся только при выпуске нового токена.

**Уведомления агента приходят владельцам, а не ответственному.** Ответственный вышел из пространства. Выберите нового через «Изменить».

**Потерян токен.** Посмотреть его повторно нельзя. Отзовите старый токен и выпустите новый.
